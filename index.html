🛒 Eenmalige instelling

Om de lijst te delen heb je een gratis Firebase database nodig. Dit duurt 3 minuten en hoef je maar één keer te doen.

```
Stap 1 — Maak een gratis Firebase project aan Ga naar console.firebase.google.com, log in met een Google-account en klik op Project toevoegen.
Stap 2 — Activeer Realtime Database In je project: klik links op Build → Realtime Database → Database aanmaken. Kies Test mode (30 dagen gratis lezen/schrijven).
Stap 3 — Kopieer je configuratie Ga naar Projectinstellingen → Jouw apps → Web app (</>). Registreer een app en kopieer het firebaseConfig object.
Stap 4 — Plak de database URL hieronder Je database URL staat in de config als databaseURL en ziet er zo uit:

💡 Tip: vraag Claude om hulp als je vastloopt bij één van deze stappen.

```
